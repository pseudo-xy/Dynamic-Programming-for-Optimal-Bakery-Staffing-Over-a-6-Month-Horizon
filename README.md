# Dynamic-Programming-for-Optimal-Bakery-Staffing-Over-a-6-Month-Horizon
This project solves a workforce planning problem for a bakery using backward induction dynamic programming. Over a 6-month period, the bakery must meet monthly demand for trained bakers while managing hiring, training, and employee departures to minimize total payroll cost.

Each month has a known requirement for trained bakers and a known number of trained bakers leaving at month's end. The decision variable is how many trainees to hire each month. Trainees cost $1,200 per month and occupy half the capacity of a trained baker during their training month (reducing effective workforce), but become fully trained the following month. Trained bakers cost $2,000 per month. The key constraint is that effective capacity — trained bakers minus half the trainees — must meet or exceed the monthly demand.
The DP formulation defines the state as the number of trained bakers available at the start of each month. The value function f(t, s) represents the minimum total payroll cost from month t onward given s trained bakers. The terminal condition after month 6 is zero (the bakery closes). Working backward, the algorithm evaluates every feasible number of trainees for each state, computing the immediate payroll cost plus the optimal future cost from the resulting next-month state, where next month's trained bakers equal the current count plus new trainees minus departures.
The feasibility constraint limits hiring: too many trainees would reduce effective capacity below demand. States where even zero trainees can't meet demand are marked infeasible. The algorithm searches over all valid hiring levels and selects the one minimizing total cost.
The output traces the optimal staffing plan from the initial state of 12 trained bakers, showing for each month the number of trained bakers, trainees hired, effective capacity, departures, resulting next-month workforce, and monthly cost. The total minimum payroll cost across all six months is reported as the final solution.
